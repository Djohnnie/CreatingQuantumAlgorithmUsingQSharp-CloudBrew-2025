# CreatingQuantumAlgorithmUsingQSharp-CloudBrew-2025
Creating a quantum algorithm using Microsoft Q# - Cloudbrew 2025

This repository contains Q# quantum algorithm examples covering:

## Contents

1. **1-Introduction** - Introduction to Q# and quantum computing basics
2. **2-Superposition** - Quantum superposition principles
3. **3-Entanglement** - Quantum entanglement examples
4. **4-Teleportation** - Quantum teleportation algorithm
5. **5-Deutch** - Deutsch algorithm implementation
6. **6-DeutchJozsa** - Deutsch-Jozsa algorithm
7. **7-CHSH** - CHSH inequality demonstration
8. **8-Shor** - Shor's algorithm for factoring
